## 2. Automotive Taxonomy Principles

1. **Standards Compliance**: Mapped directly against SAE J3016 (ADAS), ISO 3833 (Vehicle Dimensions), ISO 15118 (EV Charging), and Euro NCAP (Safety).
2. **Zero Redundancy**: Replaces legacy 47 web-scraped categories with 10 coherent engineering domains.
3. **Web-Optimized & Accessible**: Every pillar provides a dedicated README with detailed attribute specifications and blueprint applicability.
